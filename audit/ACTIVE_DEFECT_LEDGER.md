## Rules for this file

- **Never delete a row.** A finding that turns out wrong is closed with evidence
  (`REJECTED WITH TECHNICAL EVIDENCE` in the Evidence column, status `VERIFIED`), not removed.
- **Statuses:** `OPEN`, `IN_PROGRESS`, `FIXED_PENDING_REVIEW`, `VERIFIED`,
  `DOCUMENTED_LIMITATION`, `BOARD_DECISION`, `BLOCKED_HARDWARE`.
- **Only a reviewer sets `VERIFIED`.** An implementation agent (`remediation-engineer`,
  `systems-reliability-engineer`, `transmit-safety-engineer`, `research-instrument-engineer`,
  `documentation-remediation-engineer`) stops at `FIXED_PENDING_REVIEW`. The reviewer named in
  the row (`.claude/agents/`) moves it on, citing their report. No agent is the board.
- **Evidence** is a test name, a mutation ID and its result, a command and its output file, or a
  file:line. "Appears fixed", "probably fixed" and "not reproducible" are not evidence.
- **Commit** is the commit that carries the fix (filled when pushed).
- The owner and reviewer columns use the agent roles in `.claude/agents/`; "board" is the
  licensed operator who owns the repository.

Owner abbreviations are spelled out in full in each row. The summary of statuses is at the end.
