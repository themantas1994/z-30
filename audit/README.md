# Audit records

Everything under `audit/` is **historical**: reports and evidence from past reviews, kept for
provenance and so that published figures can be reproduced. It describes the repository as it
was when each audit ran, including code that has since been deleted. It is not current guidance.
For how the project works today, read [`SPEC.md`](../SPEC.md), [`docs/`](../docs/README.md) and
[`wiki/`](../wiki/Home.md); where they disagree with an audit, they are right.

Finding identifiers (`F-01`…, `C-01`…, `N-01`…) in code comments and documentation refer to
these reports; the 2026-09-28 list is in
[`2026-09-28-agent-team-review/07-board-packet.md`](2026-09-28-agent-team-review/07-board-packet.md).
Two working files that tracked fix status, `ACTIVE_DEFECT_LEDGER.md` and
`ACTIVE_REMEDIATION_HISTORY.md`, were removed in the 2026-10-06 documentation cleanup; links to
them inside older reports no longer resolve, and the files remain in git history. The evidence
rules are in [`EVIDENCE_POLICY.md`](EVIDENCE_POLICY.md).
